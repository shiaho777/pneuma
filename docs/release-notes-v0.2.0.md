# v0.2.0 · 模型配置自动对齐

填模型 ID，其余自动对齐。

## 新增

- **models.dev 目录对齐**：内置 324 家供应商 / 9515 个聊天模型快照（带来源与时间戳，`npm run` 脚本可刷新）。输入模型 ID 自动检索，确认后即对齐上下文 / 最大输入 / 最大输出 / 工具调用 / 推理 / 视觉 / 温度 / 模态 / 成本。
- **ZCode 式供应商管理 UI**：供应商列表 + 详情（Base URL / API 格式 / API Key 显隐 / 模型列表：上下文徽章、置顶、编辑、删除、启用开关）；可从目录一键添加供应商，Base URL 与协议自动填充。
- **三协议适配**：OpenAI 兼容 / Anthropic Messages / Gemini streamGenerateContent，全部流式 + 工具调用解析。
- **规格驱动运行时**：max_tokens / temperature 按模型规格下发；上下文窗口按 context − output − system 自动裁剪历史；tool_call=false 的模型自动降级文本表达格式（拆句/状态行约定）。
- 多供应商配置本地持久化；旧单配置自动迁移。

## 验证

23 个自动化测试（新增三协议请求体对齐 / 工具降级 / 上下文裁剪）；浏览器真机验证 qwen3-max 自动对齐全流程通过。
