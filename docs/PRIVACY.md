# 隐私声明

## 收集什么

**零。** 无账号、无遥测、无崩溃上报、无广告、无评分纠缠。

## 存哪里

全部在本机浏览器 IndexedDB（库名 `pneuma`）：消息、记忆、角色、动态、会话、接口配置（含你自填的密钥）、引导/更新状态。导出备份为开放 JSON 格式，无锁定。

## 发往哪（网络请求清单）

| 请求 | 触发 | 去向 | 默认 |
|---|---|---|---|
| 模型对话/生图/语音 | 你发送消息或触发工具 | 你自配的 Base URL，直连 | 演示模式不发 |
| 更新检查 | 自动（可关）或手动 | api.github.com，ETag 条件请求 | 仓库未配置时不发 |

除此之外无任何网络请求。密钥只存本机，不经过任何项目服务器。

## 权限

Web 端仅文件选择（导入角色卡/人格包/备份）与下载（导出），均用户手势触发，拒绝有降级（不导入仍可聊天）。

## 可验证

开源 MIT；构建产物可本地复现（`npm run verify`）；安全上报见 SECURITY.md。
