# v0.5.0 · 记忆会呼吸，设定会触发

调研同类开源项目后，把值得借鉴的四类机制**自行实现**落地（只借思想，不复制代码）。

## 新增

### 1. 记忆生命周期
`active → faded → archived` 三态。强度 = 时间指数衰减（半衰期 36h）与情绪加权（72h 内时间主导，之后情绪主导）+ 重要性 + 激活加成（≤0.24）。低强度转淡忘，淡忘满 7 天归档；归档条目仅在查询足够相关时才被召回。**反复提起的事记得更牢**：写入走 `addOrReinforce`，bigram 相似 ≥0.72 判重后强化既有记忆而非堆叠新条目；检索命中即强化。钉住记忆强度恒 1、永不淘汰。

### 2. 自动提取 + 冲突审查
每 20 条新消息增量提取 ≤6 条长期事实。置信度 ≥0.78 自动入库；与旧记忆中等相似（0.35–0.72）判为**可能冲突**、或置信度不足者，进入**待审队列**交用户裁决——绝不自动覆盖旧记忆。导演模式新增「待审记忆」面板，可采纳/忽略，并显示冲突对照。

### 3. 世界书触发引擎
关键词（主/辅 and-or）、常驻条目、**确定性概率**（哈希 seed = 会话:条目:轮次，同参数结果可复现）、扫描深度 20 条、字符预算 3000、优先级与特异度排序、三注入位（人格层/记忆层/场景层）。导演模式可增删条目、编辑关键词与内容、调概率与注入位。人格包导出/导入携带设定集。

### 4. 心声跨轮延续
新增 `set_inner` 工具：角色可记录情绪、挂念、还没说出口的打算，**延续注入下一轮场景层**，用户不可见。导演模式「心声延续」面板可查看当前内心状态。

## 验证

45 个自动化测试（新增 19 个：记忆衰减/归档召回门槛/去重强化/冲突识别、世界书关键词与概率确定性/预算/注入位、心声延续，以及 5 个经运行时的端到端集成断言）。边界 gate 通过，构建成功。
