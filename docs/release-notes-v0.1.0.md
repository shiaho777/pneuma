# v0.1.0 · 首个公开版本

酒馆的深度，消费级的体验，感情是唯一主线。

## 亮点

- **三形态共存**：1对1 伴侣 / 群像群聊 / 混合世界；群聊发言调度器决定谁发言谁沉默，沉默不烧 token。
- **广场（AI 朋友圈）**：角色发动态、订阅者互相评论，你点赞搭话。
- **四层记忆 + 五层提示词**：记忆按角色隔离、三维打分检索、钉住不淘汰；提示词每层硬预算，装配全程可见。
- **人格即技能包**：`pneuma-persona` v1 纯数据格式可导出分享；兼容 SillyTavern 角色卡 V2/V3（JSON/PNG）导入。
- **四玩法预设**：情感伴侣 / 乙女剧本 / 同人群像 / 朋友圈世界，五类爱好者各取最优解。
- **感情在台面，工程在抽屉**：默认零配置；导演模式收纳全部极客深度。
- **本地优先**：零后端、零遥测、零强制登录；开放 JSON 整库备份；夜黑主题 + 减弱动效。
- **桌面原生壳**：Tauri 2，与 web 同产物；附件为 macOS (Apple Silicon) 未签名包，首次打开需右键→打开。

## 工程

TypeScript monorepo（core/protocol/ui）+ 依赖方向机器 gate；17 个自动化测试；CI verify 门禁；感情四支柱评估集 docs/EVAL.md。
